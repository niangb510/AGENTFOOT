Synchronisation Cloud (Supabase)

Configurez une base de données gratuite Supabase pour que vos modifications (articles, photos, joueurs) s'affichent instantanément pour tous les visiteurs du site, sans rebuild Netlify.

-- SQL à exécuter dans l'éditeur SQL de Supabase pour créer la table :
CREATE TABLE site_data (
  key TEXT PRIMARY KEY,
  value JSONB
);

Sauvegarde Globale du Site

Exportez ou importez toutes les données du site (articles, joueurs, services, page agence et configuration) en un seul fichier JSON.

Comment publier pour tous les visiteurs ? Après avoir personnalisé le site dans ce navigateur, exportez la sauvegarde puis importez-la sur l'ordinateur de publication (ou le navigateur utilisé pour mettre à jour le site) afin que les changements soient visibles par tout le monde. Les données sont stockées dans le navigateur (localStorage).
